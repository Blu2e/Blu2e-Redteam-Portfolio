# 웹 어플리케이션 정찰 - 진행 기록

## 실습 환경
 - 공격자 측 : Kali Linux (10.10.10.3)
 - 대상 서버 : Ubuntu Server (10.10.10.4)
 - 대상 어플리케이션 : OWASP Juice Shop
 - 대상 포트 : TCP 3000
 - 실습 네트워크 : RedTeam-Lab (10.10.10.0/24)

## 수행 작업
 - Ubuntu Target에 Docker 설치
 - OWASP Juice Shop Docker 이미지를 내려받고 컨테이너 실행
 - Kali 브라우저에서 http://10.10.10.4:3000 접속 성공
 - Nmap으로 대상의 3000번 포트 스캔 및 서비스 정보 조사

## 확인 결과
 - Docker 컨테이너가 실행 중인 상태 확인
 - 웹 브라우저에서 Juice Shop 화면 표시 확인
 - Nmap에서 3000/tcp open 상태 확인
 - HTTP 응답과 여러 응답 헤더가 관찰됐으나 Nmap의 서비스 식별 결과는 명확하지 않음
