# OpenSSH 취약점 정보 조사

## 실습 목적
 - 탐지한 OpenSSH 버전과 관련된 공개 취약점 자료를 검색
 - 설치된 패키지와 업데이트 후보 버전 비교
 - 공개된 보안 수정 내역을 조사하여 추가 검증이 필요한 항목 파악

## 대상 정보
 - 운영체제: Ubuntu Server 24.04.5 LTS
 - 서비스: OpenSSH
 - 대상 IP: 10.10.10.4
 - 최초 설치 패키지 버전: 1:9.6p1-3ubuntu13.19

## SearchSploit 검색

### 특정 버전 관련 자료 검색
 - searchsploit openssh 9.6

 - 확인 결과
  - Exploits: No Results
  - Shellcodes: No Results

 - 해당 검색어로는 결과를 찾지 못함

### 검색 범위 확대
 - searchsploit openssh

확인 결과
 - 여러 OpenSSH 관련 자료가 검색
 - 검색 결과에는 다양한 소프트웨어 버전과 취약점 유형이 포함

결과 해석
 - 검색 결과가 없다는 이유로 취약점이 없다고 판단할 수 없음, 반대로 관련 자료가 검색됐다고 해서 대상 서버에 해당 취약점이 적용된다고 결론 내릴 수도 없음
 - 검색 결과의 영향 버전, 취약점 조건, 운영체제별 보안 패치 정보를 추가로 확인 필요

## 패키지 버전 조사

### 설치 버전 및 후보 버전 확인
 - apt policy openssh-server

 - 패키지 목록 갱신 전 확인 결과
  - Installed: 1:9.6p1-3ubuntu13.19
  - Candidate: 1:9.6p1-3ubuntu13.19

### 패키지 목록 갱신
 - sudo apt update
  - 이 명령어는 패키지 저장소의 목록 정보 갱신, 설치된 OpenSSH 패키지를 직접 업그레이드하는 작업은 아님

### 업데이트 가능 여부 확인
 - apt list --upgradable openssh-server

 - 확인 결과
  - 업데이트 후보 버전: 1:9.6p1-3ubuntu13.20
  - 기존 설치 버전: 1:9.6p1-3ubuntu13.19

저장소에서 기존 설치 버전보다 높은 버전을 제공 확인

### 패키지 변경 기록 조사
 - apt changelog openssh-server

 - 확인 결과
  - 여러 SECURITY UPDATE 항목이 표시
  - SFTP 디렉터리 탐색, GSSAPI 인증 처리 등과 관련된 보안 수정 내역 포함

 - 결과 해석
  - 변경 기록에서 보안 수정 항목을 확인했으나, 각 항목이 대상 서버의 실제 취약점과 일치하는지는 별도 검증 필요
  - 패키지에 업데이트 후보가 있다는 사실만으로 기존 설치 버전이 특정 취약점에 실제로 영향을 받았다고 단정 불가

## 확인 결과 요약
 - SearchSploit으로 OpenSSH 관련 공개 자료 검색
 - Ubuntu 패키지의 설치 버전과 업데이트 후보 버전 비교
 - 패키지 변경 기록에서 보안 수정 항목 확인
 - 검색 결과만으로 대상 서버의 취약점 존재 여부를 확정하지 않음

## 추가 조사 사항
 - Ubuntu 공식 보안 공지에서 대상 패키지에 영향을 주는 취약점과 수정 버전 확인
 - 각 취약점의 영향 조건과 대상 서비스의 구성 조건 비교
 - 검증 근거가 확보된 항목에 한해 적용 가능성 판단
