# Blu2e Red Team Portfolio

## About Me

안녕하세요. 빅데이터·정보보호학과 재학중인 장원재라고 합니다.
현재 저는 정보보안 레드팀을 목표로 공부하고 있습니다.

직장을 다니면서 학교의 지원을 받을 수 있는 기회가 생겼고,
현재 자리에서 단순히 능력을 업그레이드하는 것보다 제가 재밌어하는 것을 직접 배우고, 나중에는 그것을 직업으로 가지고 있으면
재미있을 것 같다는 생각으로 학교를 다니기 시작했습니다.

학교에서 보안과 분석 관련된 여러 내용을 접하면서 점점 더 흥미를 느끼게 되었고,
특히 문제를 하나씩 분석하고 해결해 나가는 과정이 게임처럼 느껴졌습니다.

물론 실제 보안 업무는 게임처럼 단순한 공격과 방어의 느낌이 아닌 엄숙한 분위기일 것이라고 생각합니다.
하지만 하나씩 배우고 이해해가는 과정이 재미있었고, 그 과정에서 보안 분야에 대한 관심이 더 커졌습니다.

그렇게 공부를 하면서 자연스럽게 레드팀 분야에 관심을 가지게 되었습니다.

## Why I Started This Project

이 포트폴리오는 GitHub 포트폴리오 수업에서만 사용하는 결과물로 끝내고 싶지 않았습니다.

현재 전공인 정보보안을 실제 진로로 발전시키기 위한 기회로 만들고 싶었고,
제가 공부하고 있는 내용을 직접 실습하고 기록하면서 실전 포트폴리오로 발전시켜 보고 싶었습니다.

그래서 가상 서버 환경에서의 모의 침투 테스트를 진행하고,
취약점을 찾고 분석한 뒤 보완하고 다시 확인하는 과정을 하나의 프로젝트로 만들어보려고 합니다.

## Learning Approach

학교 수업을 본격적으로 시작하기 전부터 보안 분야에 관심이 있었고,
관심을 가지게 된 이후 직접 사용되는 프로그램들을 찾아 설치하고 하나씩 사용해보며 조금씩 공부하고 있었습니다.

학습 과정에서 필요한 부분은 AI의 도움을 받기도 했습니다.
다만 AI가 제시한 내용을 그대로 사용하는 것에 그치지 않고, 직접 실행해보고 결과를 확인하면서 내용을 분석하고,
이해되지 않는 부분은 찾아보거나 수정하는 과정을 거쳤습니다.

이 포트폴리오에서는 단순히 결과를 보여주는 것보다
제가 어떤 내용을 공부했고, 어떤 문제를 만났으며, 그 문제를 어떻게 해결하면서 이해하게 되었는지를 기록하려고 합니다.'

## Project Goal

아직 배우고 있는 단계이기 때문에 처음부터 완벽한 침투 테스트를 수행하는 것을 목표로 하지 않습니다.

네트워크, Linux, 보안 기초부터 하나씩 공부하고, 배운 내용을 가상 환경에 직접 적용하면서
제가 이해한 내용을 실제로 설명하고 활용할 수 있는 수준까지 만드는 것을 목표로 합니다.

최종적으로는 이 과정을 정리하여
레드팀 분야로 나아가기 위한 하나의 실전 포트폴리오로 완성하고 싶습니다.
